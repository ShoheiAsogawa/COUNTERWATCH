COUNTERWATCH · DISCORD BOT SETTINGS

このページはボットの設定チェックリストです。下のプロンプトを AI に渡せば、Portal 手順・.env・起動・動作確認まで実行させられます。トークンはチャットに貼らないでください。

1. Discord Developer Portal

  1. applications → New Application → COUNTERWATCH
  2. Bot → Add Bot → Message Content Intent ON → Save
  3. Reset Token → DISCORD_BOT_TOKEN（画面に出したら即 .env へ）
  4. OAuth2 → Application ID → DISCORD_CLIENT_ID
  5. Permissions 2147593216 / scopes bot applications.commands

招待URL（Client ID を入れて開く）:

https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID&permissions=2147593216&scope=bot%20applications.commands

2. .env に書くキー

DISCORD_BOT_TOKEN=
DISCORD_CLIENT_ID=
DISCORD_LISTEN_ALL=1
DISCORD_CHANNEL_NAMES=counterwatch,アンチ,overwatch,ow
GITHUB_REPO=
GITHUB_BRANCH=main
GITHUB_KNOWLEDGE_PATH=bot/knowledge.json
GITHUB_SYNC_SECONDS=180
GIT_AUTO_PULL=0

LISTEN_ALL=1 は専用部屋向け。名前で絞るなら 0。

起動: リポジトリルートで pip install -r requirements.txt → python3 -m bot.bot

3. チャンネルでの確認

  • /role dps /side attack
  • テキスト: gibraltar pharah mercy reinhardt lucio brigitte
  • スコアボード画像 + キャプション（マップと敵名）
  • 返信にヒーローの顔画像が付くこと
  • 管理者: /reload（GitHub 同期）
